Keep Android Open — F-Droid repository

A self-hosted F-Droid repository for the unofficial Keep Android Open awareness app.

Repository URL
https://tsunderswapelnina.github.io/keepandroidopen-fdroid/repo

Add it to F-Droid

  1. Install the F-Droid client.
  2. Open Settings → Repositories → Add repository.
  3. Enter the URL above and confirm.
  4. Pull to refresh, then search for Keep Android Open.

Then tap the link to add it directly: f-droid.org/F-Droid.apk

Other ways to install

  • GitHub Releases (direct APK)
  • Obtainium (auto-updates from the GitHub repo)

This is an independent, unofficial app and repository. It is not affiliated with or endorsed by the official Keep Android Open campaign.
